## Описание

Программа состоит из двух частей:

1. **Рекурсивные алгоритмы**
   - факториал;
   - числа Фибоначчи;
   - количество цифр в числе;
   - бинарный поиск.

2. **Простые сортировки**
   - пузырьковая сортировка;
   - сортировка вставками;
   - сортировка выбором.

Также выполнено сравнение рекурсивных и итеративных реализаций, а для сортировок проведён анализ производительности на почти отсортированных массивах.

## Реализованные возможности

- Рекурсивные и итеративные версии алгоритмов.
- Проверка граничных случаев и некорректного ввода.
- Сравнение времени работы рекурсивных и итеративных решений.
- Реализация трёх простых сортировок без использования готовых STL-алгоритмов.
- Анализ времени работы на почти отсортированных массивах.
- Подсчёт сравнений и перемещений для сортировок.
- Вывод итоговой таблицы сложности.

## Среда разработки

- Язык программирования: C++17
- IDE: Microsoft Visual Studio
